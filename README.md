# OpenCV Face & Hand Gesture Detection Project

## Project Overview
This project demonstrates **real-time face detection and hand gesture detection** using **OpenCV** and **YOLO**, implemented in **Python 3.9**. The objective is to understand and apply computer vision techniques for detecting and tracking human features from a live video stream.

The project is built as a **learning-based implementation**, following tutorials and explanations by **Paul McWhorter**, with practical experimentation and customization.

---

## 🛠️ Tech Stack
- **Language:** Python 3.9  
- **Computer Vision Library:** OpenCV  
- **Object Detection Model:** YOLO  
- **Input Source:** Webcam (Real-time video)

---

## Features
- Real-time face detection using OpenCV  
- Hand detection and gesture recognition  
- Live webcam feed processing  
- Bounding boxes drawn around detected faces and hands  
- Beginner-friendly and modular code structure
